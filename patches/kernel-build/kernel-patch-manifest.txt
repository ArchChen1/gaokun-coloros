# 没打、且短期内也不打算打的：
#
#   dts/*            24 条全部打不上。这批补丁改的是 sc8280xp-huawei-gaokun3-camera.dtsi
#                    这类拆分后的文件，7.2.9 的树里 gaokun3 还是单文件
#                    sc8280xp-huawei-gaokun3.dts，那个 dtsi 不存在。要打这批，
#                    得先把内核升到已经拆分 dtb 的上游（7.3/7.4），或者手工移植。
#                    既然我们只换 ESP 里的 Image、dtb 用原厂，这批先搁置。
#   wifi/*           27 条是 ath11k 的。这台机器上 WiFi 跑的是高通 qcacld 那一支，
